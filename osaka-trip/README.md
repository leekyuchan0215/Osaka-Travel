# 규찬 지민 오사카 여행 ❤️ — 2026.11.16~19

새 일정으로 갱신한 오사카 여행 PWA. 날짜별 방문 순서, 지도 번호 마커, 구글맵 길찾기, 지하철 노선 색상 안내, 매장별 체크리스트, 방문 완료 체크를 포함합니다.

## 변경 내용

- **DAY 1** 난바 CITY 몽벨 → 난바 파크스(Standard Products·Bshop·LUSH) → 숙소 → 이치란 → GAP → PARCO(HUMAN MADE·치이카와랜드·PLAZA·Hands) → 로손 → 숙소 → 도톤보리 → 리키마루(21:45~23:00)
- **DAY 2** 구로몬시장 → 다카시마야 → 난바 → USJ → 도톤보리 → 세븐일레븐·패밀리마트
- **DAY 3** 아크테릭스 → GU·유니클로 → 마츠모토키요시 → 규카츠 → 해유관 → @cosme → 몽벨 → 살로몬 → 아식스 → Bshop → 돈키호테 난바센니치마에
- **DAY 4** 숙소 → 난카이 난바 → 라피트 07:00 → 간사이공항 → 김해
- 체크리스트 **193개**: 매장별 별도 그룹, 체크 상태는 방문 여부와 별도로 **각 휴대폰 로컬 저장**.

## 기존 GitHub 저장소에 반영하는 방법 (Windows)

1. ZIP을 압축 해제합니다. 내부 `osaka-trip` 폴더의 파일을 **기존** `Osaka-Travel/osaka-trip` 폴더에 덮어씁니다. **프로젝트 중첩 폴더를 만들지 마세요.**
2. PowerShell에서 기존 `osaka-trip` 폴더로 이동해 실행합니다.
   ```powershell
   npm.cmd install
   npm.cmd run build
   npm.cmd run dev
   ```
3. `http://localhost:5173`에서 바뀐 일정과 체크리스트를 확인합니다.
4. GitHub Desktop에서 변경 파일을 커밋한 후 **Push origin** 합니다.
5. Vercel이 기존 GitHub 저장소의 push를 감지해 자동으로 다시 배포합니다. 별도의 신규 Vercel 프로젝트를 만들 필요 없습니다.
6. 아이폰 홈 화면의 기존 아이콘에서 다시 앱을 엽니다. PWA 캐시가 남아 이전 화면이 보이면 앱을 완전히 닫고 다시 열거나 Safari에서 사이트 새로고침 후 재접속하세요.

## 조작

- 상단 `1~4일차`와 `목록/지도` 탭으로 전환합니다.
- 일정 제목을 탭하면 **교통 경로, 구매/먹거리 체크리스트, 지도 열기**가 보입니다.
- 구매 체크와 방문 완료는 독립적입니다. 두 아이폰 사이에서 자동 동기화되지 않습니다.
- 체크 내용은 브라우저 로컬 저장소에 유지되지만 캐시·사이트 데이터 삭제 시 사라집니다.
- 지도는 **방문 순서 직선 안내선**이며 실제 도로 경로가 아닙니다. 실제 도보·전철 길찾기는 Google 지도 버튼으로 확인하세요.
- GPS를 허용하면 파란색 현재 위치 마커를 표시하고 해당 위치로 이동합니다.
- 오프라인에서는 미리 캐시한 일정과 체크리스트를 확인할 수 있지만 지도 타일과 구글맵 길찾기는 인터넷이 필요합니다.

## 주의

- 매장별 영업시간은 전달한 여행 일정에 적힌 참고 시간과 일부 공식 정보를 반영했습니다. **임시휴무/실시간 재고/열차 배차는 확정하지 않았습니다.**
- 로손, 세븐일레븐, 패밀리마트, 마츠모토키요시는 정확한 지점을 지정하지 않아 일부 지도 좌표는 표시하지 않거나 **동네 대표 지점의 대략적인 위치**로 표시됩니다.
- 11/19 07:00 라피트를 타려면 숙소에서 난카이 난바역까지의 도보 시간을 감안할 때 **06:30 출발은 빠듯**합니다. 06:15 이전 출발을 권장하며, 실제 좌석 지정 시간을 우선합니다.
- 2026년 11월부터 일본 면세는 소비세 포함 결제 후 출국 시 세관 확인에 따른 환급 방식으로 전환됩니다. 일본 관광청/세관 및 매장 안내를 확인하세요.
- 신규 일정과 기존 방문 체크는 일부 ID가 같아 유지될 수 있습니다. 필요하면 하단 `방문·구매 체크 초기화`를 사용하세요.
